# User Roles

## Confirmed Role Model
Authenticated platform **User** (Default header `X-User-Id: user_default`).

## User Capabilities
- create/open/save music projects,
- use browser studio (Arranger, Lyric & AI Vocal Studio),
- add/play instruments (Piano, Synth, Bass, Drums, Strings, Guitar),
- create/arrange tracks & clips,
- record ideas via microphone (PitchTracker) or keyboard,
- request AI assistance (Natural Language, Lyrics-to-Melody, Harmony, Arrangement, Continuation, Build Around, Instrument Recommendation, Mood Variation),
- preview/accept/reject AI suggestions,
- export music (WAV).
