# AI Music Design

## AI Role
AI is a **Music Copilot**. It suggests, explains, continues, transforms, recommends, and assists.

It must not silently take ownership of the creative process.

## Context
AI requests use relevant context:
- prompt text / lyrics,
- selected key & scale,
- active instrument,
- project structure & base melody notes.

## Suggestion Lifecycle
```text
Request → Processing (Spring Boot) → Preview → Accept / Reject → Apply to DB
```
