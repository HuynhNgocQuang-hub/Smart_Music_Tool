# User Roles

## Confirmed Role Model
At this requirement stage, only a generic authenticated **User** is confirmed.

Do not invent additional persisted roles before use cases require them.

## User Capabilities
Potentially:
- create/open/save music projects,
- use the browser studio,
- add/play instruments,
- create tracks,
- record ideas,
- request AI assistance,
- preview/accept/reject AI suggestions,
- export music.

Exact permissions follow approved requirements.

## Proposed Future Role Concepts
NOT approved backend roles yet:
- Collaborator
- Administrator
- Moderator
- Creator/Artist
- Premium User

Define exact permissions before adding role enums or authorization policies.
