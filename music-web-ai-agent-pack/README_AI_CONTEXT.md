## Separation of Concerns
- Requirements = what the system must do.
- Business Rules = rules that must always hold.
- Workflows = how users/system move through a process.
- Architecture/Design = how the solution is structured.
- Skills = how an AI agent should implement/review code.

`PROPOSED` items are not automatically implementation scope.
